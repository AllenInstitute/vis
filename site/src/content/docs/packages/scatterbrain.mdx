## Installation

To install the `@alleninstitute/vis-scatterbrain` package, run the following command in your terminal. `@alleninstitute/vis-core`, `@alleninstitute/vis-geometry`, and `regl` are [peer dependencies](../../getting-started/using-packages#peer-dependencies), so they're installed alongside it:

<PackageManagerTabs
    npm="npm install @alleninstitute/vis-scatterbrain @alleninstitute/vis-core @alleninstitute/vis-geometry regl"
    pnpm="pnpm add @alleninstitute/vis-scatterbrain @alleninstitute/vis-core @alleninstitute/vis-geometry regl"
    yarn="yarn add @alleninstitute/vis-scatterbrain @alleninstitute/vis-core @alleninstitute/vis-geometry regl"
/>
